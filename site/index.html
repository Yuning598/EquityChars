四个先要读懂的术语Four terms to understand first
Excess return
资产总收益扣除文献指定的无风险基准后的收益。Total return net of the risk-free benchmark specified by the study.
Formation period
用于测量特征或历史收益、据以形成组合的观察窗口。The observation window used to measure a characteristic or past return before forming portfolios.
Breakpoint
将横截面样本划分为组别的规则，例如中位数或分位数组。The rule that partitions the cross section, such as a median or quantile cutoff.
Weighting / holding horizon
组合内资产权重，以及形成后收益被计算的期限。Asset weights within the portfolio and the period over which post-formation returns are measured.

CLASSIFICATION CRITERIA

多空方向的判定准则

H−L
文献按照特征值排序，构造多头高特征值组合与空头低特征值组合。
L−H
文献按照特征值排序，构造多头低特征值组合与空头高特征值组合。
非两端多空组合
文献采用回归系数、多变量预测模型、事件研究或模型加权组合；该类检验不对应简单的两端多空组合。
证据来源
人工摘录依据审计记录；自动摘录依据关键词检索。所有判定均应回溯至原始文献。
引文语言
论文题名、组合构造与证据摘录保留原文表述。
