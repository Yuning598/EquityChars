学习前先区分四个概念Four distinctions before reading the evidence
Bond-level excess return
单只债券总收益相对于无风险基准的超额部分。A bond’s total return net of the risk-free benchmark.
Zero-cost long-short return
多头与空头腿按共同权重规则相减后的组合收益。The return from subtracting the short leg from the long leg under a common weighting convention.
Duration adjustment
剔除与利率期限暴露相关的收益成分，以识别信用相关部分。Removing the return component associated with interest-rate duration exposure to isolate credit-related variation.
Primary-source locator
可以回到原文验证的定位句和页码，而不是概述性结论。A locating passage and page number that can be checked in the original paper, not a summary claim.

RETURN DEFINITIONS

四种收益对象必须分开

“Excess return”在公司债文献中并非唯一口径。

01

单债券超额收益

rei,t = r̃i,t − rft

常用一个月国库券收益作为无风险利率；债券总收益包含价格、应计利息与票息。

02

零成本多空收益

rLSt = rLt − rSt

若多头权重合计 +1、空头合计 −1，共同无风险利率代数抵消；方向仍须按论文定义。

03

持续期调整收益

rDAi,t = ri,t − rTsyi,t

扣除与债券现金流久期匹配的国债反事实收益，识别信用部分而非简单现金超额收益。

04

模型加权收益

rMt = w′t−1rt

IPCA、深度特征或最大夏普组合的权重由联合估计决定，不能逐变量预设 H−L。
