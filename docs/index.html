About

Open Asset Characteristics Data collects replication code, documentation, and update notes for asset-level characteristics used in empirical asset pricing research.

The current release covers U.S. equity characteristics. Corporate bond data is reserved as the next dataset family, so the site is organized around datasets rather than around one repository.
