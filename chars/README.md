# Quantactix Chars Subsite

This directory is the static Chars website intended to be mounted at:

`https://quantactix.com/chars/`

The entrypoint is `index.html`. All page links, scripts, data files, and PDFs use
relative paths so the directory can be copied into a static host or framework
public directory as a self-contained subsite.

For Quantactix integration, add a Project page link to `/chars/`.
